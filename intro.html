Project Brief

Use your creativity to research and complete a personalised project in groups or on your own!


Some of you will have now completed portfolio-building projects across diverse topics like Web Development, Artificial Intelligence and Game Development.
We hope this sparked some ideas about the potential of the tools at our disposal. If you're new here, we’ll work closely with you to ensure you’re fully supported as you navigate the self-guided process.

For today's session I would like to see you all thinking about something you would like to create and researching how to do that. The Code Club Facilitators will be coming round and helping you to plan, showing you where to look to get started and giving recommendations. The portal is where you will come each week to check recommended resources for you to progress your projects and you can even check this at home! Your recommended resources will be stored under a tile on the portal home page, labelled with your project name. So make sure to think of a good one!

If you are struggling with what to do here are some suggestions:

  • Create a Webpage using HTML and CSS
  • Write a short Python application. You can use Pygame, Tkinter (for graphic interfaces), etc
  • Learn to use Blender or use Tinkercad to create 3D Assets
  • Use Minecraft Education Edition to create a Minecraft adventure map for everyone to play. Using redstone, command blocks and block code
  • Create a game using Game Maker, Flowlab, MakeCode Arcade, Roblox Studios, GDevelop, etc (search free online game makers)
  • Create a project Using a MicroBit. (loads of examples on Makecode)
  • Create a Scratch project

Here is a short trailer on some projects we've previously completed together in our Code Clubs!

Spend some time looking at these different options and seeing what you like. This is by no means an exhaustive list. You might already have something in mind and doing something completely different is okay. Just remember you only have until the end of the Autumn term.
If you're still stuck ask someone to come and help you decide or see whether you can parter up with someone!
